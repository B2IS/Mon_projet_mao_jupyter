Principes UX — Règles globales
Accessibilité & Touch
✓ Taille cible tactile min 44×44px
✓ Contraste texte min 4.5:1 (WCAG AA)
✓ Icônes toujours accompagnées d'un label
✓ Focus ring visible (2px, couleur blue-800)
✓ Statuts jamais véhiculés par la couleur seule
✓ Respect prefers-reduced-motion
Performance & Responsive
✓ Dynamic import pour Leaflet, PDF, charts
✓ Offline-first (Zustand persist)
✓ Mobile 375px · Tablette 768px · Desktop 1440px
✓ Animations 150–300ms, transform/opacity only
✓ Skeleton screens sur chargements >300ms
✓ Sidebar collapsed icon sur tablette
RBAC & Visibilité
✓ Items sans accès : masqués, pas disabled
✓ DIR_DPE/PMO : tous domaines même si vides
✓ Tabs admin sensibles : ADMIN exclusif
✓ canGlobal = niveau RBAC ≤ 1
✓ Aucun menu vide affiché (no ghost entries)
✓ Lecture seule = formulaires non éditables
Formulaires & Feedback
✓ Label visible par champ (jamais placeholder seul)
✓ Erreur sous le champ concerné, couleur rouge
✓ Toast auto-dismiss en 4 secondes
✓ Confirmation avant toute action destructive
✓ Bouton submit : loading spinner + disabled
✓ Champs requis marqués * rouge
